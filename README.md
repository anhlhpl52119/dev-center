## Installation

<details>
<summary>
Make sure to install the dependencies:
</summary>

```bash
# npm
npm install

# pnpm

pnpm install

# yarn

yarn install

```

</details>

### Development Server

<details>
<summary>
Start the development server on local
</summary>

```bash
# npm
npm run dev

# pnpm

pnpm run dev

# yarn

yarn dev

```

</details>

### Production

<details>
<summary>Build the application for production:</summary>

```bash
# npm
npm run build

# pnpm
pnpm run build

# yarn
yarn build
```

</details>

<details>
<summary>
Locally preview production build:
</summary>

```bash
# npm
npm run preview

# pnpm
pnpm run preview

# yarn
yarn preview
```

</details>

Check out the [deployment documentation](https://nuxt.com/docs/getting-started/deployment) for more information.
